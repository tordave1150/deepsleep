# สถานะการจัดทำ

**สถานะรวม · Partial completion** ส่งมอบบทเรียนภาษาไทยครบ 11 บท, Lab Walkthrough ครบ 20 เล่ม และเอกสารทบทวน 6 รายการ มีข้อจำกัดด้านขอบเขตและ output ตามรายการด้านล่าง

## ผลตรวจต้นฉบับ

- สำรวจ Drive เมื่อ 2026-11-14 ครบ 11 โฟลเดอร์ Class และ 7 โฟลเดอร์ย่อย พบ 12 PDF และ 20 Notebook ตรงกับรายการในโจทย์ ไม่พบ Notebook ใน class09 และ class11
- ดาวน์โหลดและยืนยัน SHA-256 ครบ 32 ไฟล์ สกัดข้อความและตรวจหน้าภาพของ PDF 481 หน้า ตรวจ Markdown, Code และข้อมูล output ของ Notebook ตามลำดับจริง 728 cells
- บันทึก 28 ไฟล์เป็น verified และ 4 ไฟล์เป็น partial เข้าถึงไฟล์ต้นฉบับได้ทั้งหมด ดูเลขหน้า เลข cell และหัวข้อที่ครอบคลุมใน [Coverage](../sources/coverage.md) และ [Manifest](../sources/manifest.json)

## ข้อจำกัดที่บันทึกไว้

- Class 09 ใช้ PDF ทั้งสองฉบับ บท Adversarial Attack ครอบคลุมความเปราะบาง วิธีประเมิน และหลักการป้องกัน รายละเอียดการทำซ้ำการโจมตีจาก PDF แรกมีขอบเขตจำกัด
- TensorBoard และ W&B มี output หรือ Dashboard ที่พึ่ง Runtime, event logs หรือสิทธิ์บริการ ส่วน Attention_ex2 มี progress widgets ที่พึ่ง Runtime ตรวจข้อความและภาพที่ฝังในไฟล์ได้
- Lab ทุกเล่มใช้การอ่านโค้ดและ output ที่บันทึกไว้ ไม่มีผลการฝึกที่รันซ้ำในงานนี้ และไม่มี External Supplement

## ผลตรวจเอกสาร

- ตรวจ relative paths และ anchors, ชื่อและลำดับบท, code fences, ตำแหน่งอ้างอิง 129 จุด และตัวอย่างโค้ด 20 ชุดเทียบกับ Notebook จริง
- เรนเดอร์สมการ LaTeX 221 นิพจน์ด้วย MathJax ตรวจภาพวงจรฝึก SVG และเรนเดอร์แผนที่แนวคิดด้วย Mermaid ในเครื่อง การแสดงผลบน GitHub ยังไม่ได้ตรวจโดยตรง
- ตรวจ Git ignore สำหรับต้นฉบับ, ผลสกัด, credentials และ outputs ไฟล์ต้นฉบับและภาพจากแหล่งเรียนอยู่ในสำเนาสำหรับตรวจงานที่ถูก ignore
